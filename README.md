# Create: New Tempest

A Minecraft 1.19.2 (Forge) mod that bridges [Create](https://www.curseforge.com/minecraft/mc-mods/create) and [Tensura: Reincarnated](https://www.curseforge.com/minecraft/mc-mods/tensura-reincarnated), adding the **Mechanical Construct** race.

- **Mechanical Construct** — machine-bodied main lineage (26 base HP, high knockback resistance); water corrodes the frame: **Corrosion** while submerged, **Paralysis** in rain.
- **Evolution tree** — 9 races across 3 branches (Titan, Warrior, Scholar); every tier unlocks skills and grows the magucule pool (up to 4,500 at apex), with EP thresholds configurable per race (50–1,000,000,000).
- **Create-flavored recipes** — crush Netherrack for a chance at Demon Essence; mix a Tensura Slime Chunk in a basin for Slime Pool items.
- Auto-injects the race into Tensura's starting/random race lists; race IDs and stats configurable in TOML.

Requires Minecraft 1.19.2, Forge 43.4.0, Java 17.

```bash
./gradlew build
```
